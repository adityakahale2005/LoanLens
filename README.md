# 💰 LoanLens — EMI & Loan Intelligence Tool

A full-stack web application for calculating EMIs, visualizing loan amortization, and comparing loan options.

## 🔗 Live Demo
https://loan-lens-pi.vercel.app

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Recharts
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Auth:** JWT
- **Deployment:** Vercel (frontend), Render (backend)

## ✨ Features
- EMI calculator with full amortization schedule
- Month-by-month principal vs interest breakdown
- Crossover month detection
- Loan comparison tool
- Calculation history per user
- JWT-based authentication
